# Полегшене середовище виконання Java для образів застосунків

- Образ застосунку містить лише ті модулі Java, які він використовує, а не повний JDK: без компілятора, заголовків і засобів розробки, тож він на кілька сотень мегабайтів менший і має меншу поверхню атаки.
- Набір модулів визначається за JAR-файлами самого застосунку, плюс типовий набір для кодувань, локалей і керування; кожен образ може замінити або розширити його.
- Полегшене середовище зберігає те, що цей образ додає під час запуску: продакшн-прапорці JVM, імпорт власних CA і тест версії. Експортер JMX для Prometheus додається на запит.
- Запуск лишається швидким: середовище має власний архів class-data sharing.
- Працює для кожного дистрибутива й серії, які публікує цей образ. Дивіться [інструкцію](../how-to/use-export.md).
