# Скомпрометовані центри сертифікації вилучено зі сховища довіри JDK

- Oracle і Temurin постачають власний `cacerts`, окремо від системного сховища; під час збирання його урізає той самий список недовіри b19, не чекаючи оновлення JDK.
- Кожен перелічений відбиток також потрапляє до списку блокування JDK, який відхиляє скомпрометований проміжний сертифікат будь-де в ланцюжку, зокрема його перехресно підписані копії.
- Компактний експорт `jlink` урізається так само, а сертифікат, імпортований під час запуску, не може повернути заблокований проміжний сертифікат.
- `B19_CA_DISTRUST` додає відбитки, а `B19_CA_DISTRUST_ENABLED=false` залишає сховище JDK у первісному вигляді.
