# Опційні метрики Prometheus через JMX

- Java-агент експортера JMX Prometheus зафіксовано в образі й приєднується до кожного виклику `java`, коли `B19_JAVA_JMX_ENABLED=true`, відкриваючи метрики JVM (купа, GC, потоки) на кінцевій точці `/metrics` для збирання Prometheus.
- Вимкнено за замовчуванням і прив’язано до loopback за замовчуванням -- жоден порт не відкривається без запиту, а адреса, порт і файл конфігурації змінюються під час виконання без перезбирання.
- Конфігурація за замовчуванням звітує метрики JVM без налаштування під застосунок; змонтуйте власну конфігурацію експортера (або вкажіть її через `B19_JAVA_JMX_CONFIG`), щоб додати правила MBean застосунку.
- Хук успадковується, тож похідні образи на основі `b19/java` отримують таку саму поведінку автоматично.
